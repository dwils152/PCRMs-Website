PCRMs homepage style directions

Thirteen mockups built with the site’s real content. Chromosome, P-value, organism, filter and tab controls are clickable. Fonts load from Google Fonts, so an internet connection is needed for the intended typefaces.

Current pick

  1. K in green with the new logoDirection K recoloured to pine and lime, with the J2 (W4) logo in the header, footer and browser tab.
  2. Browse pageChoose a genome, chromosomes and a p-value cutoff; Search opens the results.
  3. Functional analysisOne page with three tabs: closest CRMs to a gene, CRMs around a gene, and TF binding sites.
  4. Download pageRelease archives per genome, with real file sizes; files not yet on the server are marked.
  5. Results pageSortable, filterable, paginated CRM table with CSV download, using synthetic data.
  6. Final logo fileslogo/final/: full logo, white version, square mark, mark without the square, favicon, and PNG icons (32, 180 and 512px).

All directions

  1. A · JournalReads like an article page in Database: serif text, abstract, numbered sections, ruled tables and references.
  2. B · Research portalEnsembl/UCSC lineage: header search, tabbed search panel, dense genome table and sidebar boxes.
  3. C · Swiss gridFlat, typographic and poster-like: big numerals, one colour band for browsing, no shadows or rounded corners.
  4. D · KaryotypeThe homepage is a chromosome picker: click chromosomes drawn to scale, then browse CRMs.
  5. E · Search-firstPubMed/Scholar-style: one search box with Gene / TF / CRM ID scopes, everything else one click away.
  6. F · Dataset recordData-repository page: authors, DOIs, filterable file list, BibTeX/RIS citation export, versions.
  7. G · DocumentationDocs-site layout: sidebar, quick start, download and analysis code in Shell, Python and R.
  8. H · Plain HTMLDeliberately unstyled: default fonts, blue links, bordered tables, native form controls. Fast and honest.
  9. I · University labUNC Charlotte green and gold, gene search in the header band, news, citation and contact boxes.
